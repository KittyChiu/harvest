# Support

Use [GitHub Issues](https://github.com/KittyChiu/harvest/issues) for confirmed
bugs and focused feature requests.

Before opening an issue:

- update GitHub Copilot CLI;
- refresh the `harvest` marketplace and affected plugin;
- check the plugin is listed with `copilot plugin list`; and
- include the plugin name, version, operating system, and reproduction steps.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.
