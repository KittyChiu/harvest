# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** option on the repository's Security
tab to submit a private report. If that option is unavailable, contact the
maintainer privately using the contact details on their
[GitHub profile](https://github.com/KittyChiu). Include:

- the affected plugin, skill, script, or version;
- steps to reproduce the issue;
- its potential impact; and
- any suggested mitigation.

You should receive an acknowledgment within seven days. Please allow time to
investigate and release a fix before disclosing the issue publicly.
