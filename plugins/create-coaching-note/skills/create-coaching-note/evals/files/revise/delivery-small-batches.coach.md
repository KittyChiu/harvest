# Coaching companion: Small batches shorten feedback loops

Parent: [Delivery](delivery-moc.md)
Companion to: [Small batches shorten feedback loops](delivery-small-batches.md)

Tags: #delivery #coaching #draft #private

## Teach

Use one small result to replace a planning assumption before committing dependent work.

## Watch for

- A plan contains an assumption that later tasks depend on.
- Review is scheduled after dependent work starts.

## Conversation

- Which assumption could most change the current plan?
- What is the smallest result that could test it?
- When must the team review that result for it to affect the next decision?

## Exercise

Steps:
1. Mark one untested assumption in the current plan.
2. Define a small result that could test it.
3. Schedule a review before dependent work begins.

Expected outcome: A proposed batch boundary and review point the team can discuss.

## Adoption

### Start

- Name the assumption each small batch is intended to test.

### Continue

- Preserve existing review practices that change later decisions.

### Stop

- Committing dependent work before reviewing the result it relies on.

## Progress signals

- Reviews occur before dependent work starts.
- Plans change when a result invalidates an assumption.
- These signals cannot prove that every batch is the right size.

## Common resistance

| Resistance | Response |
| ---------- | -------- |
| Smaller batches create more coordination. | Explore where coordination cost exceeds the value of earlier learning. |
