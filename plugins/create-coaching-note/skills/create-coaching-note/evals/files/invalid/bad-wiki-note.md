# Small batches shorten feedback loops

Parent: [[delivery-moc|Delivery]]

## Pattern

> When uncertainty can change the plan, deliver a small reviewable batch, because each result improves the next decision.

## Practice

- Review one small result before dependent work starts.

## Why it works

Each result replaces an assumption with evidence.

## Signals

- The plan depends on an untested assumption.

## Learning

Small review points exposed mistaken assumptions.

## Constraints

- Some work cannot be separated safely.
